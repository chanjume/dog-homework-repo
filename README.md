# The Dog Ate My Homework: Funniest Excuse

A dog explains why the homework got eaten — in the dog's own voice, with
a twist that redefines the setup: it wasn't homework, it was lunch.

> It smelled exactly like the bacon sandwich you ate over it. I didn't eat your homework — I finished your lunch.

Run with `node main.ts` (Node 22). The entry is 111 characters, inside
the 1–200 character gate.
